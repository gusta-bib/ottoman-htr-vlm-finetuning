# Limitations (Section 5.4)

1. **Single GPU constraint.** All experiments used a single NVIDIA RTX 4070 Ti SUPER (16 GB VRAM). Multi-GPU training and larger batch sizes may yield different dynamics.

2. **Unverified ID ground truth.** The in-distribution test set (815 lines) uses automatically aligned references that have not been manually verified. Observed CER values on ID therefore conflate model error with reference noise.

3. **Domain specificity.** All training data comes from Ottoman court registers (*şer'iyye sicilleri*) in Riqa script. Generalization to other Ottoman document types (firmans, letters, literary manuscripts) or other scripts (Naskh, Talik) has not been evaluated.

4. **Pseudo-label circularity.** Blocks B and C were generated by earlier-generation models trained on Block A. Although each generation's pseudo-labels were filtered by alignment score, systematic biases in the generator could propagate through the self-training loop.

5. **Single random seed.** Fine-tuning runs used a single seed. Variance across seeds has not been quantified.

6. **Quantization trade-off.** All reported results use GPTQ W4A16 quantization. The accuracy gap between full-precision and quantized inference has not been isolated.
