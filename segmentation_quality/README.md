# Segmentation Quality Evaluation

This directory contains evaluation annotations, model prediction caches, and evaluation tools following the ICDAR 2009 Handwriting Segmentation Contest (Gatos et al., 2009) protocol.

## Files in this Directory

- `ground_truth_segmentation.json`: Ground truth line bounding boxes annotated across 20 representative out-of-sample manuscript pages (778 lines).
- `predictions_20_pages.json`: Predicted line bounding regions generated by the AHDoc line detector (1,492 regions).
- `evaluate_icdar_segmentation.py`: Evaluation script computing MatchScore, Detection Rate (DR), Recognition Accuracy (RA), and F-Measure (FM).
- `segmentation_sensitivity_table.csv`: Sensitivity table across acceptance thresholds (at T_a = 0.95: DR 18.51, RA 9.65, FM 12.69).

## How to Reproduce

Run the evaluation script:
```bash
python evaluate_icdar_segmentation.py
```
